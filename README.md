<h1>A basic slackbot that runs 24/7</h1><br>
A bot with different commands that can be called in slack at any time.<br>
<img width="618" height="169" alt="Screenshot 2026-09-12 131055" src="https://github.com/user-attachments/assets/dc730a2a-49e5-4711-ad43-4c3745499d98" /><br>
Trial URL: https://hackclub.enterprise.slack.com/archives/C0P5NE354<br>
To use it go to the hack club slack and use the bot spam channel attached<br>
Call it with /woah-cool-bot-help and it will give you a list of commands you can use<br>
Features:<br>
Ping - to check bot latency<br>
Joke - to get a random joke<br>
Roll - to get a random number 1-6<br>
Flip - flip a coin<br>
Weather - weather for Wellington, NZ<br>
Catfact - gets a random cat fact
